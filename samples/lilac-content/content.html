Content styles in lilac

Blockquotes, lists, code and tables. Each one shows a few variations you can pick from.

These are the pieces that go inside an article besides plain paragraphs. Hover, click and scroll around, and toggle the theme to see both versions. Everything here follows the lilac accent. Read more about HTML elements if you want the full list.

Blockquotes

A blockquote sets a quotation apart from your own words. Three variations:

Standard

A good page explains itself before anyone has to ask a question about it.

Style guide note

Quiet (just a bar, no fill)

Keep the rule thin and let the words carry the weight.

Pull quote (centered, large)

Small details are what make a site feel like yours.

Checklist (checkboxes use the accent)

Definitions

Accent
The one color a page uses for links, highlights and buttons.
Tint
The accent mixed with transparency, used for soft backgrounds.
Wash
An even lighter tint, used for hover rows and linked entries.

Code

Inline code looks like --c-spot or color-mix(). Keyboard keys look like Ctrl + Shift + R. Longer code goes in a block with a label and a copy button.

index.html 
<!-- A term with a glossary note -->
<span class="note" data-key="mites">MITES</span>
styles.css 
/* The accent, softened into a tint */
.note {
    background: color-mix(in srgb, var(--c-spot) 14%, transparent);
}
script.js 
// Load the notes, then build the page
const res = await fetch('notes.json');
const notes = await res.json();
